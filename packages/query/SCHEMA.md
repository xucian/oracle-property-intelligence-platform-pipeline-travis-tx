# DuckDB schema: sources and readers

`schema.sql` (DDL) and `post_load.sql` (indexes, FTS, CHECKPOINT) are the interface between `packages/deploy-build`
(writes) and `packages/query` / `apps/api` (read). DuckDB 1.5.6, `@duckdb/node-api` 1.5.6-r.1. This file says where every column
comes from. Contract references are to `docs/api-contract.md` (v1) definitions.

Paths: `K` = `<kit>/skills/use-oracle/runtime/data/travis`. `RUN` = `K/runs/20261018T143520Z-t5-full`.
`SH` = `RUN/shards/sNNNN` (89 shards, 5,000 properties each). Run record = `runs/<run_id>.json`;
publication record = `runs/<run_id>.publication.json`; manifest = `publish/<run_id>/manifest.json`.
`SEED` = `SH/seed.csv` (the TCAD roll rows behind each shard, `source_*` columns). `CAP` = `K/permits/v1792239863/`.
`LINK` = `RUN/global/link-a1/sNNNN.jsonl` (per-shard permit links) and `permits-internal.jsonl` (the kit's classification of all
2,380,707 captured permits, a reconciliation reference, not a serving input).

Reading rules for every endpoint: `as_of` is the request's `open_duration_as_of` (today, UTC date). Nothing query-time is stored.

| Query-time value     | Formula                                                                                                                                                                       |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `open_duration_days` | `open`: `as_of - open_since`; `stalled`: `static_duration_days`; else NULL. `open_duration_basis`: `today` / `static_duration_basis` / NULL                                   |
| `days_since_expiry`  | `stalled` and `expires_date` not NULL: `as_of - expires_date`; else NULL                                                                                                      |
| long-open            | open or stalled roofing permit with `open_duration_days >= long_open_years * 365` (properties: `as_of - open_roofing_min_open_since`, or `stalled_roofing_max_duration_days`) |
| `owner_tenure_years` | `round(date_diff('day', deed_date, as_of) / 365.25, 1)`; NULL without `deed_date`                                                                                             |
| `distance_miles`     | haversine (3958.8 mi) from `(lat, lon)` for properties, `(radius_lat, radius_lon)` for permits                                                                                |
| `aged_roof`          | `roof_age_years > roof_age_min` (strict)                                                                                                                                      |

## search_centers, search_center_aliases (GET /v1/search-centers, MCP resolve_search_center)

`search_centers`: `GROUP BY situs_city_norm` (kind `city`, `name` = most frequent printed `situs_city`) and `GROUP BY situs_zip` (kind `zip`), over
`properties` with non-NULL `lat`; `lat`/`lon` = mean; `parcel_count` = parcels with that city/ZIP (all, as the basis says; coordinates not required for the count);
`basis` = `centroid of <n:,> parcels with situs city <NAME>` / `... situs ZIP <zip>`. `search_center_aliases`: reviewed alias list (deploy-build constant,
versioned `alias_version`), e.g. `WESTLAKE` -> `WEST LAKE HILLS`. Matching order: exact `name_norm`, prefix, alias; sort exact first, then `parcel_count` desc.

then `open_duration_days` desc nulls last, then `permit_id`. Text search: see below.

`permit_text` <- `permits` where `is_text_indexed`: `*_norm` = lower-case, accents stripped, alias list applied (`re-roof`/`re roof`/`reroof` -> `reroof`),
same function applied to query text. FTS index `fts_main_permit_text` created by `post_load.sql`. Query:
`fts_main_permit_text.match_bm25(permit_id, ?, fields := 'description_norm,permit_class_norm,work_class_norm', conjunctive := 1)` (`conjunctive := 0` for `match=any`),
after dropping stopwords from the query. `match_snippet.field` = the first of description, permit_class, work_class whose raw text contains a query stem.
`total` counts all matches before `limit`.

## contractors, registry_candidates, license_candidates (Contractor)

`contractors`: `GROUP BY contractor_attribution_key` over `permits` (company/trade/phone/address = most frequent printed values; `printed_names` = distinct `contractor_full_name`;
address = `address1[, address2], city zip`). Counts: `permit_count`, `open_permit_count` (`status_group = 'open'`), `roofing_permit_count`, `needs_review_permit_count`
(`status_group = 'needs_review'`). `bbb_*` = `deploy.bbb_*`.
`registry_candidates`: matcher `exact_unique_normalized_name` of `contractor_company_name` against `business_records.name_norm` where the name is unique in the source's
universe (`K/matcher/*.names.parquet`: `keys_under_name = 1`; franchise universe = `tx-comptroller-franchise-tax-statewide.names.parquet`); `matched_field = 'company_name'`.
`license_candidates`: same against each license source, for `contractor_company_name` and `contractor_full_name` (`matched_field` `company_name` / `printed_name`).
Both carry the candidate's `unpublished_source` by join to `business_records` / `license_records`. `official_identity` is always null in v1. `license_candidates`
is `null` when `license_records` is empty, else `[]`+rows.

## Published lexicon mirrors (schema `lex`)

`lex.county_<table>` (25 tables) and `lex.pi_<table>` (6 tables) are the Parquet parts of `SH/county-a1/tables/<table>/` and `SH/property_improvement-a1/tables/<table>/`
loaded verbatim (all 89 / 88 shards, column names and types as published, `shard` added). `lex.county_geometry.polygon` is loaded as NULL.
`lex.properties_index` unpivots the published `properties` tables: every non-`property_cid` column is named by a schema CID and holds the data-group CID.
Readers: `properties` and `permits` are built from these; the API reads them only for CID display (`record_cid`, `property_cid`, `data_group_cid` are copied to the serving tables).
The published `address` tables carry no address text; situs and mailing text come from `SEED`.
